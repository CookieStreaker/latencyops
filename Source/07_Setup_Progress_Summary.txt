🚀 LatencyOps — Project Blueprint & Setup Progress Report
1. Executive Summary & Product Vision
Product Name: LatencyOps

Core Value Prop: Real-time API health, uptime, and rate-limit alerting monitor built specifically for engineering teams, CTOs, and backend leads. It catches latency spikes and 429 (Too Many Requests) errors before users do.

Target ICP: B2D (Business-to-Developer) market—funded early-stage startups and tech teams with business credit cards looking for zero-bloat, 2-minute API monitoring.

Launch Goal: 4-Week MVP execution focused strictly on product output, reliability, and securing initial paying B2B customers ($29/month Pro tier).

2. Tech Stack & Engineering Standards
Backend Engine: Go (Golang 1.22+) for high-concurrency worker pools and probes.

State & Cache Layer: Redis 7+ for sliding-window rate limit error counters and sub-millisecond status evaluation.

Persistence DB: PostgreSQL 16+ (Supabase) for users, workspaces, endpoints, and alert logs.

Frontend Dashboard: React / Next.js with Tailwind CSS, Shadcn UI primitives, and Lucide icons (Vercel/Linear dark mode aesthetic).

Security Guardrails: Full adherence to OWASP Top 10 API Security rules (strict tenant isolation WHERE id = $1 AND workspace_id = $2, HttpOnly JWT cookies, and SSRF URL protection).
